# CareerBrand AI v11.0

Нархоз университетінің АКТ емтиханы үшін жасалған жеке бренд, CV, портфолио және мансап агенті платформасы. Негізгі тіл — қазақша; орысша және ағылшынша интерфейстері бар.

**Жаңа:** Gemini және OpenAI API провайдерлерін таңдай алады. Google Gemini тегін деңгейінің қауіпсіздігі мен конфигурациясы: [START_HERE_V11_KK.md](START_HERE_V11_KK.md).

## Жергілікті іске қосу

Node.js 20+; қосымша npm тәуелділіктері қажет емес.

```bash
npm start
```

Браузерде: `http://127.0.0.1:3000`. API кілтінсіз сайт, CV, портфолио және офлайн синтетикалық агент демосы жұмыс істейді.

## Тексерулер

```bash
npm test
npm run smoke
```

## Интернетке жариялау

`render.yaml` тегін жоспарды көрсетеді. Қолмен жасалған Render қызметі үшін `HOST=0.0.0.0` параметрін орнат. Кілттерді **GitHub-қа жүктеме**. Gemini-ді қосу нұсқаулығы: [START_HERE_V11_KK.md](START_HERE_V11_KK.md).

## Дерек шектеулері

Gemini Free tier сұраулары Google өнімдерін жақсартуға пайдаланылуы мүмкін. Нақты жеке түйіндеме/ЖСН/телефондарды пайдалану ұсынылмайды. Деректерді сақтау жергілікті браузерде жүргізіледі. HeadHunter болмаса, агентке ойдан шығарылған оқу деректерін беру режимі бар; олар нақты вакансия ретінде ұсынылмайды.
