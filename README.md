# CareerBrand AI — университеттік жоба (MVP v1.1)

**Негізгі тіл — қазақша.** Орысша және ағылшынша интерфейстер бар. Сайт жеті бөлімнен тұрады: Басты бет, Жеке бренд стратегиясы, Түйіндеме, Портфолио, Бейнетаныстырылым, Еңбек нарығы, ЖИ кеңесшісі.

Бұл — оқу мақсатындағы жұмыс істейтін MVP бастапқы коды. Нақты AI API-ге және бос орындар провайдеріне қолжетімділік пайдаланушының аккаунты мен провайдер шарттарына байланысты; оларсыз шынайы деректерді қолдан жасап көрсетпейміз.

## 1. Іске қосу

1. [Node.js](https://nodejs.org/) **20+** орнатыңыз.
2. ZIP архивін ашыңыз.
3. Windows-та `START-WINDOWS.bat` файлын екі рет ашыңыз, немесе жоба бумасында терминалдан `node server.mjs` орындаңыз.
4. Браузерден `http://localhost:3000` ашыңыз.

Сыртқы npm кітапханасы жоқ: `npm install` қажет емес. Тоқтату — терминалда `Ctrl+C`.

## 2. Нақты ЖИ-чатты және агентті іске қосу

**API кілтін `app.js` немесе `index.html` ішіне салуға болмайды.** Кілт тек сервер ортасында сақталады.

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="YOUR_KEY_HERE"
$env:OPENAI_MODEL="gpt-4.1-mini"
node server.mjs
```

macOS / Linux:

```bash
OPENAI_API_KEY="YOUR_KEY_HERE" OPENAI_MODEL="gpt-4.1-mini" node server.mjs
```

API — ChatGPT Plus жазылымынан бөлек ақылы қызмет болуы мүмкін. Кілтіңіздегі модельге рұқсатты және қолданылатын тарифті тексеріңіз.

- `POST /api/chat`: соңғы 10 хабарлама, таңдалған тіл, қысқартылған пайдаланушы профилі және қолжетімді вакансия мысалдары арқылы ЖИ кеңесшіге сұрау жасайды.
- `GET /api/jobs`: HeadHunter бос орындар API-нен берілген сұрау және аймақ бойынша ең көбі 20 бос орын алады.
- `POST /api/agent`: сервер вакансияларды алып, дағды аталымдарын санап, пайдаланушы түйіндемесімен салыстырады. AI кілті қосулы болса, **сол шектеулі деректер бойынша** түсіндірме жасайды. Кілт жоқта `mode: "rules"` — **ЖИ емес, ережелік талдау** ретінде анық көрсетіледі.

Сервер `OPENAI_API_KEY` жоқ болса, жасанды түрде нейрожелі жауабын көрсетпейді.

## 3. Вакансиялар туралы ескерту

Нақты дереккөз: [HeadHunter API құжаттамасы](https://api.hh.ru/openapi/redoc) және [hh.kz API](https://dev.hh.kz/). HeadHunter ресми API-інде авторизация мен сұрау шарттары бар; кей сұраулар CAPTCHA не access қателерімен аяқталуы мүмкін. Сондықтан **барлық желіде және аккаунтта API жұмыс істейді деп кепілдік берілмейді**. Тиісті API құқықтарын тексеріңіз. Егер қолжетімді жеке OAuth токені болса, серверге `HH_TOKEN` ретінде беруге болады.

Дағдылар жиілігі — бірінші беттегі (ең көбі 20) вакансияның тақырыбы және қысқаша талаптарынан табылған анық терминдер. Бұл толық еңбек нарығын, вакансиялардың бәрін немесе жалақы статистикасын сипаттамайды. Агент әр көрсеткішке нақты іздеу сілтемелері мен уақытын пайдалануға бағытталған.

## 4. Интерфейс мүмкіндіктері

- Қазақша / орысша / ағылшынша мәзірлер мен нұсқаулықтар; бастапқы тіл — қазақша.
- Жеке бренд мақсаты, артықшылықтары, аудиториясы, ұсынатын құндылығы және 30 күндік жоспар.
- Түйіндемені өңдеу, толтырылуын тексеру, **Print → Save as PDF** тәсілімен сақтау.
- Портфолиоға жоба қосу / өшіру.
- Жеке профильге негізделген бейнетаныстырылымның **қарапайым мәтіндік шаблоны** (ЖИ генерациясы емес).
- Нақты жауап алынғанда вакансияларды іздеу және жеке дағды айырмашылықтарын салыстыру.
- API кілті қосулы болса, үш тілдің бірінде ЖИ-чат.
- Жергілікті профайл және жобалар браузердегі `localStorage` ішінде сақталады.
- Басты беттегі **«Жобаның авторлық мәліметтері»** бөлімінде автор, университет/факультет, мамандық, пән және жыл көрсетіледі. Олар footer-ге шығарылады — **міндетті түрде өз мәліметтеріңізбен толтырыңыз**.

**Ескерту:** Пайдаланушы енгізген CV мәтіні тілді ауыстырғанда автоматты түрде аударылмайды; тек сайттың интерфейсі және ЖИ жауаптары тілдік режимге бейімделеді.

7 автоматты тест бар: үш тілдегі сөздіктер, барлық бөлімдердің көрсетілуі, сервер жауабы, кілт жоқта айқын қате, дағды талдауы, жалған (mock) вакансия провайдері және жалған (mock) AI API арқылы сервер интеграциясы. **Mock тесттің өтуі нақты OpenAI/HeadHunter серверлеріне желілік қосылым сәтті болғанын білдірмейді.**

## 6. Қауіпсіздік және шектеулер

- Бұл MVP-те тіркелу, нақты дерекқор, cloud deploy, құпия ақпаратты қорғау бойынша өндірістік аудит жоқ.
- Профиль браузерде сақталады. ЖИ-чатқа хабарлама жіберген кезде профиль деректері сыртқы API-ге жіберіледі. ЖСН, үй мекенжайы, құпия құжаттар енгізбеңіз.
- Пайдаланушылар қосқан жетістіктер тексерілмейді. Шын емес деректерді CV-ге жазуға болмайды.
- ЖИ қате кеңес бере алады. Ұсынымдарды өзіңіз тексеріңіз.
- HeadHunter API-нің нақты қолжетімділігі сыртқы сервиске тәуелді.
- PDF экспорттау — браузердің print диалогы; бейне түсіру және аудио файлдарын жүктеу әлі жасалмаған.
- Мультимедиаға арналған AI-суреттер галереясы және нақты бейне жүктеу — келесі кезеңнің жұмысы.
