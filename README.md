# CareerBrand AI v10.0

Нархоз университетінің АКТ пәні үшін жасалған, жеке бренд пен мансапқа арналған үш тілді (қазақша, орысша, ағылшынша) оқу веб-жобасы.

**Негізгі тіл — қазақша.** Сайтта CV, портфолио, бренд стратегиясы, бейнетаныстырылым мәтіні, мультимедиа, түйіндеме кеңесшісі және еңбек нарығы агентінің интерфейсі бар.

## Ең бірінші ашатын файлдар

- **`START_HERE_V10_KK.md`** — Windows және Mac/Linux арқылы сайтты ашу.
- **`DEPLOY_V10_KK.md`** — GitHub және Render Free көмегімен төлемсіз жариялау қадамдары.
- **`COST_SECURITY_V10_KK.md`** — нақты қандай нәрсе тегін, неден абай болу керек.
- **`PREVIEW-OFFLINE.html`** — серверсіз бастапқы көрініс және ережелік оқу демосы; шынайы ЖИ емес.
- **`CHANGELOG_V10_KK.md`** — v9-дан кейінгі өзгерістер.

## Жергілікті іске қосу

Node.js 20 немесе жаңасы керек. Буманың ішінде:

```bash
node server.mjs
```

Ашылатын мекенжай: `http://127.0.0.1:3000`.

**Тегін функцияларды тексеру үшін OpenAI API кілті қажет емес.** Серверге кілт қосылмаса, нақты нейрожелілік чат жауап бермейді, бірақ CV редакторы, портфолио, профиль, видео мәтіні және анық белгіленген сынақ деректерімен аналитика қолжетімді.

## Автоматты тесттер

```bash
npm test
npm run smoke
npm run check
```

Қолданыстағы сайт сілтемесін қауіпсіз тексеру (ақылы ЖИ сұрауларын жібермейді):

```bash
node scripts/smoke.mjs https://YOUR-APP.onrender.com
```

GitHub-та `.github/workflows/verify.yml` әр push кезінде тест жүргізеді.

## Интернетке жариялау

`render.yaml` файлы `plan: free` параметрін **нақты бекітеді**. Бұл маңызды: параметрсіз жаңа веб-сервис әдепкі ақылы жоспарға түсуі мүмкін. Бастапқы тегін жариялауда ешбір API кілтін енгізбе. Құпия кілттерді GitHub-қа салуға болмайды. Жүйе нақты интернетке әлі жарияланбаған, жариялау үшін GitHub және Render аккаунтындағы пайдаланушы әрекеті қажет.

## Шынайылық пен шектеулер

- Оқу демосындағы вакансиялар **синтетикалық**, нақты нарық статистикасы емес.
- HH API мен OpenAI API-нің нақты сыртқы қызметтері қосылғаннан кейін ғана олардың жұмысын бөлек растау керек.
- AI_DAILY_CALL_LIMIT — **сервер жадындағы уақытша есептегіш**, ақылы шығынға қатаң шек емес.
- Браузердегі профиль тек сол браузерде сақталады; қажет болса резервтік файлды экспортта.
- Университеттік Word есебі мен презентацияның бұрынғы v4 нұсқалары — **қазіргі v10 нұсқасына бейімделмеген** тарихи материалдар. Оларды соңғы қорғауға өзгеріссіз тапсырма.
- Музыка файлы — процедуралық аудио; мұғалімнің «AI-музыка» шартын толық орындады деп есептеуге болмайды.

## Қауіпсіздік

`.env`, API кілті, жеке деректер, құпия код және аккаунт құпиясөздері GitHub репозиторийіне және ChatGPT чатына жіберілмеуі тиіс. Ашық серверге нақты `OPENAI_API_KEY` немесе `HH_CONTACT_EMAIL` орнатылғанда кемінде 16 символдан тұратын `DEMO_ACCESS_CODE` қажет. Бұл ортақ код — толық авторизация жүйесі емес.
